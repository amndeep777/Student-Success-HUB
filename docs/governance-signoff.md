# Governance sign-off checklist

All items are required before Phase 5 go-live.

- [ ] Data Protection / Privacy Officer approved consent text versions.
- [ ] Dean or Head of Department approved the retention schedule.
- [ ] Student Welfare / Counselling Head approved feedback-sharing purpose and workflow.
- [ ] Student representative reviewed student-facing wording.
- [ ] Anonymisation method approved, including pseudonym mapping restrictions.
- [ ] Minimum group size of five verified in aggregate reports.
- [ ] All required `governance_configs` rows have `approved = true`.
- [ ] Production startup check passes.
- [ ] Consent version is stored on every consent record.
- [ ] Withdrawal, deletion, and retention jobs have been tested.

Until all items are complete, the release is not approved for production.
