# Risks and open items

- Demo authentication must be replaced by university SSO before any pilot.
- LiveKit room-token creation and Google Calendar OAuth need university credentials and provider configuration.
- PDF malware scanning needs an approved scanner service or ClamAV deployment.
- PostgreSQL and object storage backups need operational ownership.
- Risk rules must be reviewed with faculty to reduce false positives.
- Student-facing wording requires the governance sign-off checklist.
- ML, mobile, panel interviews, and more calendar providers are optional later work.
