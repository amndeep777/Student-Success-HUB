# MVP permission summary

| Role | Main access |
|---|---|
| Student | Own consents, interviews, feedback, notes, attempts, and results |
| Mentor | Assigned academic context, notes, questions, descriptive review, human flag review |
| Counsellor | Assigned support context and feedback only after student consent |
| Interviewer | Assigned interviews, waiting rooms, notes, and feedback |
| Admin | Configuration and operational management; aggregate interview analytics only |
| Data-steward | Audit, consent, retention, and privacy review |
